# 额度与计费规则

本文说明 VoiceLinkVR 当前的资源额度、套餐计费、加油包和功能扣费规则。实际显示与可购买项目以账号中心页面为准。

## 1. 什么是资源额度？

VoiceLinkVR 使用“资源点”计算服务用量。每个账号每天都有一份订阅日额度，调用语音识别、翻译、TTS、语音克隆等功能时，会按功能类型扣除对应资源点。

每日额度优先消耗；当日额度不足时，如果账号有可用加油包，会自动继续消耗加油包额度。

## 2. 每日额度什么时候重置？

每日额度按 UTC 自然日重置，对应北京时间每天 08:00 左右重置。

加油包额度不会每天重置，只会在实际使用时扣减，直到余额用完或订阅到期。

## 3. 所有额度项说明

| 额度项 | 含义 | 当前规则 |
| --- | --- | --- |
| 订阅每日额度 | 当前套餐每天可使用的资源点上限 | 免费 1000 点/日；付费套餐见下方套餐表 |
| 今日已用订阅额度 | 今天已经从订阅每日额度中扣除的资源点 | 只统计订阅日额度消耗，不包含加油包消耗 |
| 今日剩余订阅额度 | 今天还可以从订阅每日额度中使用的资源点 | 今日剩余订阅额度 = 订阅每日额度 - 今日已用订阅额度，最低为 0 |
| 加油包余额 | 当天订阅额度不足后可继续使用的额外资源点 | 不会每天重置；使用时逐次扣减 |
| 加油包累计购买量 | 历史累计购买过的加油包资源点 | 仅用于展示累计购买量，不代表当前可用余额 |
| 加油包到期时间 | 加油包可用期限 | 跟随订阅到期时间；订阅过期后不可继续使用 |
| 总资源消耗 | 查询时间范围内总共扣除的资源点 | 包含订阅额度消耗和加油包消耗 |
| 订阅额度消耗 | 查询时间范围内从每日订阅额度扣除的资源点 | 用于计算每日剩余额度 |
| 加油包消耗 | 查询时间范围内从加油包扣除的资源点 | 不影响当天订阅剩余额度 |
| 已扣费请求次数 | 查询时间范围内真正扣除资源点的请求次数 | 不等于资源点数；一次请求可能扣 1、2、3 或 4 点 |
| 成功请求数 | 查询时间范围内成功完成的请求数 | 用于用量统计，不一定等于扣费请求次数 |
| 失败请求数 | 查询时间范围内失败的请求数 | 一般不扣资源点 |
| 被限速次数 | 查询时间范围内因频率或额度限制被拒绝的次数 | 一般不扣资源点 |
| 总请求数 | 查询时间范围内成功、失败、被限速等请求总数 | 用于统计请求量，不等同于资源消耗 |

## 4. 限速项说明

| 限速项 | 当前规则 | 说明 |
| --- | --- | --- |
| 免费用户接口频率 | 10 资源/分钟 | 和每日额度同时生效 |
| 匿名测试账号接口频率 | 10 资源/分钟/IP | 按 IP 统计，不按账号统计 |
| 订阅用户接口频率 | 不额外限制速率 | 当前主要按每日额度限制；如果账号被单独配置限速，则以账号配置为准 |

限速和额度是两套规则：限速控制单位时间内请求频率，额度控制可消耗的资源点。

## 5. 免费用户有多少额度？

免费用户每日 800 点额度，限速 8 次/分钟。

游客或默认测试账号同样是每日 800 点，但额度和限速按 IP 统计，不按账号统计。

## 6. 付费套餐额度是多少？

目前按照当前付费套餐主要按每日额度限制，默认不额外设置分钟级限速。

## 7. 加油包是什么？

加油包用于在当天订阅额度用完后继续使用服务。

当前规则：

| 加油包价格 | 增加额度 |
| --- | ---: |
| ¥5 | 5000 点 |

加油包可以按 ¥5 的倍数购买，例如 ¥10 对应 10000 点。

加油包需要有效付费订阅才能购买和使用。加油包到期时间跟随订阅到期；订阅过期后，加油包额度不可继续使用。

## 8. 哪些请求会扣额度？

只有成功完成的收费功能请求会扣额度。失败请求、被限速请求一般不扣额度。

如果接口返回成功状态，即使识别结果为空、内容被过滤或返回空文本，也会按对应功能扣除额度。

## 10. 额度消耗顺序是什么？

1. 优先消耗当天订阅额度。
2. 当天订阅额度不足时，自动消耗可用加油包额度。
3. 如果订阅额度和加油包额度都不足，请求会被拒绝，并提示资源额度不足。

## 11. 购买和续费有哪些限制？

| 项目 | 当前规则 |
| --- | --- |
| 订阅购买月数 | 1-24 个月 |
| 首次购买 | 免费用户、已过期用户或首次购买用户可以选择任意付费档位 |
| 续费 | 已有付费用户默认按当前套餐续期 |
| 升级 | 只能升级到更高价格档位 |
| 降级 | 当前不支持降级到更低档位 |
| 加油包购买条件 | 必须有有效付费订阅 |
| 加油包购买步长 | ¥5 为一个步长，每 ¥5 增加 5000 点 |
| 加油包购买上限 | 当前没有固定公开上限，以账号中心可选金额为准 |

## 12. 续费怎么计算？

续费金额为：

```text
套餐月价 × 购买月数
```

购买月数支持 1-24 个月。

免费用户、已过期用户或首次购买用户，可以选择任意付费档位开通订阅。已有付费用户续费时，默认按当前套餐续期。

## 13. 升级怎么计算？

已有付费用户可以升级到更高档位。升级费用按当前剩余订阅时间折算，规则为：

```text
(目标套餐月价 - 当前套餐月价) × 折算月数
```

升级后，剩余订阅时间会按当前套餐与目标套餐的价格比例折算到新套餐上。

当前不支持降级到更低档位。

## 14. 额度用完后怎么办？

如果当天订阅额度用完，可以选择：

1. 等待下一次每日额度重置。
2. 在有效付费订阅期内购买加油包。
3. 升级到更高额度的套餐。

如果订阅已过期，需要先续费或重新开通付费套餐，才能继续使用付费权益和加油包。

## 15. 如何查看自己的额度和用量？

可以在账号中心查看当前套餐、每日额度、今日剩余额度、加油包余额、订阅到期时间和历史用量。

用量统计会区分订阅日额度消耗和加油包消耗，方便确认额度来源。
